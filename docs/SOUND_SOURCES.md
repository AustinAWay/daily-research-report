# Sound sources (downloaded by scripts/fetch_sounds.sh, never committed)

| pack | license | used for | upstream |
|---|---|---|---|
| VSCO-2 Community Edition | CC0 1.0 | orchestral hits, piano, strings | https://github.com/sgossner/VSCO-2-CE |
| Virtuosity Drums | CC0 1.0 | acoustic kit (Samples/mid) | https://github.com/sfzinstruments/virtuosity_drums |
| TR-808 (fischer) | CC0 / public domain (see repo) | 808 kick, snare, hats, clap (bd8, sd8, ch8, cp8 ...) | https://github.com/tidalcycles/sounds-tr808-fischer |
| Kenney Interface Sounds | CC0 1.0 | UI clicks, ticks, confirms | https://kenney.nl/assets/interface-sounds |

Everything else (pads, bass, leads, risers, impacts, Shepard tone) is synthesised in numpy by scripts/music.
pedalboard (GPL-3) is used as a processing tool only; it ships no audio content and is not redistributed here.
Check each upstream license yourself before publishing; if a pack's terms change, replace it with another CC0 pack.
